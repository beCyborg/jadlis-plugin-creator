# Как участвовать / Contributing

## Русский

- Форк → ветка → PR; одна тема на один PR.
- Перед PR прогоните локально: `claude plugin validate . --strict` и `gitleaks git . --no-banner`.
- README.md (RU) и README.en.md (EN) правятся парой: одинаковый набор и порядок `##`-секций.
- Тексты пишутся вместе с Claude Code; за содержание и решения отвечает владелец репозитория.

## English

- Fork → branch → PR; one topic per PR.
- Before opening a PR run locally: `claude plugin validate . --strict` and `gitleaks git . --no-banner`.
- README.md (RU) and README.en.md (EN) change together: same set and order of `##` sections.
- Texts are written together with Claude Code; the repository owner is accountable for content and decisions.
